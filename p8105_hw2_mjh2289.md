``` r
subway_df <- read_csv("Data/NYC_Transit_Subway_Entrance_And_Exit_Data.csv") |> 
  janitor::clean_names() |> 
  select(line, station_name, station_latitude, station_longitude, route1:route11, entrance_type, entry, vending, ada) |> 
  mutate(
    entry = case_match(
    entry,
    "YES" ~ TRUE,
    "NO" ~ FALSE
  )
)
```

This dataset providers technical information on every entrance or exit
for each subway station in New York City, such as station name, subway
line, station longitude and latitude, entrance or exit longitude and
latitude, entrance and exit accessibility, station staffing, and more.
Nineteen data points on each of the 1868 entrances or exits comprise the
clean data. Data cleaning involved removing some variables not relevant
to the analysis (e.g., station staffing), and changing the type of one
variable from character to logical type. The raw and clean data are tidy
because each row represents a single entrance or exit.
